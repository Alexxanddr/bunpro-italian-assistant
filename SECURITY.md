# Sicurezza

Per segnalare una vulnerabilità, apri una segnalazione privata tramite GitHub Security Advisories. Non pubblicare dettagli sfruttabili in una issue.

Indica versione dell'estensione, versione di Chrome, pagina Bunpro interessata e passaggi minimi per riprodurre il problema. Non allegare dati personali o informazioni dell'account.
