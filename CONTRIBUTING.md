# Contribuire

1. Crea un fork e un branch dedicato.
2. Mantieni l'estensione priva di dipendenze esterne e compatibile con Manifest V3.
3. Verifica sintassi JavaScript, manifest e pacchetto ZIP.
4. Prova Learn Grammar, Learn Vocab e Review su Bunpro.
5. Apri una pull request descrivendo comportamento, test e schermate interessate.

Non includere dati personali, contenuti dell'account Bunpro o chiavi segrete nelle issue e nelle pull request.
